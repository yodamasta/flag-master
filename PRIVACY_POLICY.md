# Politique de Confidentialité - FlagMaster

Dernière mise à jour: 28 avril 2026

FlagMaster est un jeu de quiz de géographie. Cette politique décrit les données utilisées par l'application.

## Données utilisées

### Mode invité
En mode invité, la progression reste stockée localement sur l'appareil. Cela peut inclure les scores, trophées, contenus débloqués, préférences audio, skins et décors équipés.

### Compte utilisateur
Si le joueur choisit de créer un compte ou de se connecter, FlagMaster peut synchroniser la progression avec Firebase. Les données synchronisées peuvent inclure le pseudo, les scores, trophées, statistiques de jeu et progression.

### Pays approximatif
L'application peut utiliser un pays approximatif pour personnaliser certains éléments de jeu. FlagMaster ne demande pas de position GPS précise.

### Achats intégrés
Les futurs achats intégrés seront traités par l'App Store d'Apple. FlagMaster ne collecte pas les informations de paiement, les numéros de carte bancaire ou les identifiants de paiement.

### Audio et haptique
Les sons, musiques et vibrations sont utilisés uniquement pour le feedback de jeu.

## Données non collectées
FlagMaster ne collecte pas de données médicales, financières, biométriques, contacts, photos personnelles ou localisation GPS précise.

## Suppression des données
Un joueur peut utiliser le mode invité sans compte. Pour demander la suppression de données liées à un compte, utiliser l'adresse ou l'URL support publiée sur la fiche App Store.

## Services tiers
FlagMaster peut utiliser Firebase pour l'authentification et la synchronisation de progression. Les achats intégrés passent par Apple App Store.
